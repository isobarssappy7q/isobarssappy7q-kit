# isobarssappy7q-kit

Validate JSON files and print a normalized form.

Small, dependency-free Python utility package generated for day-to-day file chores.
Standard library only — no third-party imports.

## Install

```bash
pip install -e .
```

## Usage

```bash
python -m isobarssappy7q_kit.cli --help
```

```python
from isobarssappy7q_kit.core import Isobarssappy7qTool

tool = Isobarssappy7qTool()
print(tool)
```
